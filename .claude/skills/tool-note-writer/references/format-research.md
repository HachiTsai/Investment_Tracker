# 標的研究筆記格式（type: research）

> `notes.py new research` 產生的空白筆記與 `notes.py check` 的檢查規則，皆以本檔為準。共通規則（frontmatter 寫法、不寫 `# 標題`、Markdown lint）與 `format-arch.md` 相同。

## 檔名

- 位置：`research/<代號>_<主題>.md`，檔名主幹必須與 `title` 相同。
- 代號必須是 `tickers` 的第一個，例如 `00882_股利追蹤`、`00878_成分股研究`。
- 不使用日期；不可含空白與 `* " \ / < > : | ? # ^ [ ]`。

## Frontmatter

| 欄位 | 必填 | 格式 | 說明 |
| --- | --- | --- | --- |
| `type` | ✓ | `research` | 筆記類型 |
| `title` | ✓ | `<代號>_<主題>` | 與檔名相同 |
| `status` | ✓ | 詞彙表 `research_status` 擇一 | 觀察／持有／放棄 |
| `created` | ✓ | `YYYY-MM-DD` | 建立日 |
| `updated` | ✓ | `YYYY-MM-DD` | 必須等於「更新紀錄」最新一筆的日期 |
| `tags` | ✓ | `[詞, ...]`，詞彙表 `tags` | 至少一個 |
| `tickers` | ✓ | `[00882, ...]` | 至少一個；第一個為檔名代號 |
| `review` |  | `YYYY-MM-DD` | 下次回頭檢查的日期，例如下次除息或財報後 |
| `related` |  | `["[[筆記名]]", ...]` | 相關筆記 |
| `aliases` |  | `[別名, ...]` | 搜尋用別名，例如基金全名 |
| `sources` |  | `[URL或來源, ...]` | 依據來源 |

研究筆記不使用 `domain` 與 `version`：研究是持續累積的觀察，以「更新紀錄」的日期追蹤，不做版本管理。

## 正文段落

依序使用以下 `##` 段落，名稱不可更改：

1. `## 摘要`：一到兩句話說清楚這個標的與目前結論。`find` 搜尋結果會顯示這段。
2. `## 論點`：為什麼持有或觀察這個標的。論點是 Hachi 的判斷；資料不足時寫「（待 Hachi 補充）」，不要代為編造。
3. `## 依據`：支持論點的事實與數據，附來源與資料日期；表格放在這裡。
4. `## 風險與反方觀點`：可能讓論點失效的事，以及反對持有的理由。
5. `## 追蹤指標`：之後要盯的數字或事件，寫清楚「看到什麼就要重新評估」。
6. `## 更新紀錄`：每次更新一個 `### YYYY-MM-DD` 小節，最新的放最上面，寫這次更新了什麼、看法有沒有改變。

## 更新研究時

- 新資料或新想法：在「更新紀錄」最上方新增 `### YYYY-MM-DD`，並把 `updated` 改成同一天。
- **不刪除舊判斷**：看法改變時，在更新紀錄寫明「原本怎麼想 → 現在怎麼想 → 為什麼」，正文改成新的結論。
- 出清或決定不投資：`status` 改為 `放棄`，檔案保留。

## 範例

```markdown
---
type: research
title: 00882_股利追蹤
status: 持有
created: 2026-10-02
updated: 2026-10-02
tags: [高股息, 股利, ETF]
tickers: [00882]
review: 2027-01-31
related: ["[[股利目標模型]]"]
aliases: [中信中國高股息]
---

## 摘要

00882 半年配息，2022–2026 年每單位年配息 0.66 到 1.21 元，五年平均 0.93。

## 論點

- （待 Hachi 補充）

## 依據

- 2026 年配息 0.45＋0.55 = 1.00（資料日 2026-10-01，FinLab）。

## 風險與反方觀點

- 配息波動大，近一年 1.00 高於五年平均 0.93。

## 追蹤指標

- 2027/1 除息金額：低於 0.40 時重新評估股利目標模型的推估。

## 更新紀錄

### 2026-10-02

- 建立研究筆記。
```
