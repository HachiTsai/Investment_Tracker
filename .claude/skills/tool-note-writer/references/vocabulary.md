# 筆記受控詞彙表（SSOT）

> `notes.py check` 會讀取本檔。frontmatter 的 `domain`、`status`、`tags` 只能使用這裡列出的詞，避免同一個概念被寫成多種說法，日後才搜得齊。
>
> 需要新詞時：先確認沒有同義詞已存在，再於對應段落新增一行 `- 詞：說明`，並與使用該詞的筆記放在同一個 commit。
> 詞本身不可含空白或逗號（Obsidian tag 限制）。

## domain

財商架構筆記所屬的領域，一篇筆記只選一個。

- 目標：財務目標與里程碑，例如年股利 50 萬
- 配置：資產配置、標的組合、市場分布
- 現金流：入金、出金、股利流向、預備金
- 股利：配息政策、再投入規則
- 風險：集中度、停損、壓力測試
- 稅務：股利稅、二代健保、海外所得
- 決策規則：買賣、加碼、換股的觸發條件
- 資料系統：APP、Investment_Tracker_Core、skill、資料流程

## status

- 草稿：還在思考，尚未採用
- 生效：目前實際遵循的規則
- 修訂中：已決定要改，新版尚未定案
- 廢止：不再使用；保留檔案作為思考軌跡

## tags

可複選，描述筆記涉及的主題。

- 高股息：高股息 ETF 或高殖利率策略
- 股利：股利收入相關
- 再投入：股息再投入
- 複利：複利成長模型
- ETF：ETF 相關
- 台股：台灣市場
- 港股：香港市場
- 中國：中國市場或中國資產曝險
- 美股：美國市場
- 日股：日本市場
- 集中度：單一標的或市場集中風險
- 殖利率：殖利率計算或比較
- 成本：持有成本、真實成本計算
- 手續費：交易手續費
- 二代健保：二代健保補充保費
- 匯率：匯率與外幣資產
- 現金部位：現金與預備金
- 再平衡：配置調整與換股
