# 基本面多維評分與量化模型規格書（SSOT）

本文件為 `fundamental-analyzer` 技能的唯一真實來源（SSOT），定義單一個股與 ETF 穿透聚合之評分演算法、權重比例與邊界條件。

---

## 1. 核心評分象限定義

所有評分標準化為 **0 至 100 分**。

### 1.1 股利可持續性評分（`divScore`）

衡量企業以實質營運現金流支撐股利發放之能力，權重分佈如下：

- **自由現金流覆蓋倍數 (FCF Coverage, 40%)**：\(\text{FCF} / \text{Dividends Paid}\)
  - \(\ge 2.0\)：100 分
  - \(1.5 \sim 2.0\)：85～100 分
  - \(1.0 \sim 1.5\)：60～85 分
  - \(0.5 \sim 1.0\)：30～60 分
  - \(< 0.5\) 或負數：10～30 分
- **盈餘配發率 (Payout Ratio, 35%)**：\(\text{DPS} / \text{EPS}\)
  - \(40\% \sim 70\%\)：100 分
  - \(70\% \sim 85\%\)：75～90 分
  - \(85\% \sim 100\%\)：50～75 分
  - \(> 100\%\) 或虧損配息：20～40 分
  - \(< 20\%\)：60 分
- **營業現金流含金量 (OCF Quality, 25%)**：\(\text{OCF} / \text{Net Income}\)
  - \(\ge 1.2\)：100 分
  - \(1.0 \sim 1.2\)：80 分
  - \(0.8 \sim 1.0\)：60 分
  - \(< 0.8\)：30 分

---

### 1.2 綜合財務健康評分（`netScore`）

衡量企業資本回報效率與資產負債表強韌度：

- **股東權益報酬率 (ROE, 40%)**：\(\text{Net Income} / \text{Total Equity}\)
  - \(\ge 20\%\)：100 分
  - \(15\% \sim 20\%\)：85～100 分
  - \(10\% \sim 15\%\)：70～85 分
  - \(5\% \sim 10\%\)：45～70 分
  - \(< 5\%\) 或負數：10～45 分
- **負債權益比 (Debt to Equity, 30%)**：\(\text{Total Debt} / \text{Total Equity}\)
  - \(\le 50\%\)：100 分
  - \(50\% \sim 100\%\)：80 分
  - \(100\% \sim 150\%\)：65 分
  - \(150\% \sim 200\%\)：45 分
  - \(> 200\%\)：25 分
- **營業利益率 (Operating Margin, 30%)**：\(\text{Operating Income} / \text{Revenue}\)
  - \(\ge 30\%\)：100 分
  - \(20\% \sim 30\%\)：85 分
  - \(10\% \sim 20\%\)：65 分
  - \(5\% \sim 10\%\)：45 分
  - \(< 5\%\)：25 分

---

### 1.3 估值與安全邊際評分（`valScore`）

- **本益比 (P/E, 40%)**：現價 / EPS
  - \(\le 12\)：100 分
  - \(12 \sim 18\)：80 分
  - \(18 \sim 25\)：60 分
  - \(> 25\)：30 分
- **股價淨值比 (P/B, 30%)**：現價 / 每股淨值
  - \(\le 1.2\)：100 分
  - \(1.2 \sim 2.0\)：80 分
  - \(2.0 \sim 3.5\)：55 分
  - \(> 3.5\)：35 分
- **當前殖利率 (Yield, 30%)**：近一年配息 / 現價
  - \(\ge 7\%\)：100 分
  - \(5\% \sim 7\%\)：80 分
  - \(3\% \sim 5\%\)：60 分
  - \(< 3\%\)：40 分

## 2. ETF 穿透聚合算法

針對 ETF 標的，取其前 \(k\) 大核心持股（預設 \(k=10\) 或已建檔之全成分股）：

\[
\text{Normalized Weight} \quad \tilde{w}_i = \frac{w_i}{\sum_{j=1}^{k} w_j}
\]

各項總體評分由歸一化權重線性加權：

\[
\text{Score}_{\text{ETF}} = \sum_{i=1}^{k} \tilde{w}_i \cdot \text{Score}_i
\]
